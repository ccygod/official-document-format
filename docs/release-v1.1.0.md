# v1.1.0 公文格式Skill：统一执行与真实属性验收

本次更新针对“样例通过，但新材料再次出错”开展重构。

- 新增config/official.json统一默认参数，保留本次用户覆盖。
- 新增pipeline.py：预检、导入母版样式、组件准备、格式化、列宽、内容对账、重复处理与包保留检查。
- 修复样式正确但文字直接覆盖字体/字号仍被放过、主题字体残留、分页控制带0仍被视为开启。
- 修复全短字段列除零、短类别列过宽、长时间安排被误当窄列。
- 按语义名称解析表格样式，仅处理标题关联的编号定义，保留无关正文列表。
- 默认从标题2开始，内容标题和正文均缩进2字符；支持明确的顶格/标题1覆盖。
- 明确分开结构通过、语义复核和WPS视觉验收，失败不交付。
- 44项自动化测试；四组本地历史材料执行回归；一个独立陌生合成案例；本机WPS检查合计10页。

不承诺所有文档自动正确；复杂结构预检分流。私有客户材料不发布。详细证据与限制见docs/validation.md。
