# v1.2.3 底层规则回归矩阵

本轮在v1.2.2矩阵基础上加入段落属性顺序规范化和反例检查，并重新执行全部组合。

- 5种格式包：公文、汇报、行业报告、学位论文、技术手册；
- 2种编号模式：自动编号、手动编号；
- 5类材料：陌生合成材料、完整公文示例、MBA方案、校企共建方案、技术方案对照报告；
- 50项组合全部通过，内容保留、二次幂等和源包部件保留全部通过；
- 55项自动化测试全部通过；
- WPS五格式批量渲染全部成功。

这轮新增的底层检查是`w:pPr`属性顺序。WordprocessingML对`pStyle`、`numPr`、`spacing`、`ind`、`jc`和`rPr`等属性有固定顺序要求，写入器会在保存前规范化，检查器会对乱序文档失败。这样可以把“文件能打开”与“OOXML结构稳定”分开验收。
