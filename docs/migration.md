# 旧标识迁移

当前技能标识为`multi-document-format`；`official-document-format`是从v1.2.3开始保留的兼容别名。仓库URL仍保留为`https://github.com/ccygod/official-document-format`，已有下载链接和历史版本不失效。旧的`artifact-template-wps`继续作为更早版本的迁移来源，不作为当前调用名。

已有旧目录时，请先备份个人修改，安装到新目录并确认加载，再移除或停用旧的完整技能副本。不要直接覆盖旧安装。旧项目文件中记录的历史路径可保留用于追溯。

本次发布操作在维护者本机保留了一个显式调用的旧名转接入口，只负责指向新技能，不是第二份完整实现。普通下载者不需要此入口。
