# v1.2.4 multi-document-format：强制风格选择入口

本次修订解决实际使用中的入口问题：用户直接调用Skill时，之前虽然文档里写了“必须选择格式”，模型仍可能直接进入读取或处理流程。

现在首轮交互必须一次性确认三项：

1. 文档风格：公文、汇报、行业报告、论文、技术手册或正式模板；
2. 正文字号：小四、四号或用户指定字号；
3. 标题编号：`automatic`自动序号或`manual`手动编号。

三项没有齐全时，入口只提问，不运行`formats`、`inspect`、角色识别和`format`。这条门禁已经写入`SKILL.md`和Codex默认提示，并加入回归测试。

验证结果：56项自动化测试通过，既有v1.2.3的50项全格式矩阵和WPS回归继续作为发布前证据。
