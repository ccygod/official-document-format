# 完整排版示例

[official-demo.docx](official-demo.docx)是首页展示的两页原创虚构示例：第一页包含主标题、一至五级标题和正文；第二页包含实际图片、图注、表题、表格及表下注释，两页均含页码。

示例使用公开母版，正文四号、1.35倍行距，已经macOS WPS实际渲染并检查。原始图像来自assets/demo-workflow.png，由本项目原创；不包含客户资料。

用`python3 examples/build_demo.py /tmp/input.docx`可以重建。再按[验收步骤](../docs/verification.md)处理；构建器只用于这个示例。
